# Independently invented native v2 family

These declarations and the digest oracle were invented from scratch for generic
compiler and future disposable mock database tests. No actual application model,
XML, table, locator or private input was consulted or transformed.

The two alternative bindings describe the same invented logical types. Future
planner tests can create a second palette with fresh values and retarget one
glyph reference, retaining other glyphs and unrelated XML. This fixture does not
claim a database has been observed or a planner/writer has executed that case.

`digest-oracle.py` independently implements the frozen byte framing in Python,
without importing Java compiler code. `expected-digests.json` records its output.
