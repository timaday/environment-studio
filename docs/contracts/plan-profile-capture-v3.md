# Internal v3 plan profile capture

Capture from the plan's original inspected content, never target values or computed
membership. Both direct capture and admitted view capture dispatch explicitly by
definition version. V3 calls a separate controlled capture port with the original
plan observation pin, original Content, explicit physical slot mappings and the
same work/view cancellation. The default v3 port refuses; the old v2 path and bytes
remain unchanged. Returned portable source is schema3 with its v3 logical digest.

Before capture, freshly verify complete original XML, physical inventory,
derived input/results, exact source inventory and original Existing provenance
against the independent plan pin. Then use V3ProfileBytesAdapter and its existing
physical-only capture/codec, never a v2 Ready wrapper. Capture includes the complete
physical graph with an explicit unique mapping for each physical entity. No donor
value, computed entity/edge/contributor or frozen derived dependency is portable.
Runtime profile revision/save remains a separate immutable workspace command.

Preserve one-MiB portable-source limits, operation ownership, one shared scratch,
original lease/revision/generation/inspection and cancellation checks before
return. Cancellation during verification, encoding or final publication refuses;
retirement/closed view cannot return a late successful capture. No captured profile
is published or saved by this operation. No route or runtime availability is added.

Acceptance: actual invented XML through shared service, exact schema3/physical-only
round trip, different source values produce identical portable content for the
same explicit neutral mappings, target edits do not change original capture,
forged original evidence/pins and computed mappings refuse, stale revision and
late cancellation refuse, and v2 capture controls retain their bytes.
