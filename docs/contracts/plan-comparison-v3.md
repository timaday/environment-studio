# Internal v3 document comparison

Extend the shared lifecycle's immutable view snapshot with optional original
and decision pins supplied by its owning plan. The legacy constructor supplies
no v3 pins; it cannot authorize v3 comparison. Original pin uses the retained
observation fingerprint and current source inventory. Decision pin uses the
same plan/revision/generation token as materialization. Snapshot construction
alone remains a value operation, never live ownership or source authority.

Before v3 Raw, Placeholders or Formatted comparison, independently reproject
complete original sources with the selected v3 model and expected original pin.
Compare physical graph, full input/result, exact sources and Existing provenance.
Observed failed rules remain inspectable. For target comparison, run the existing
complete materializer with independently supplied original/decision pins and
retained draft, then compare the entire returned target Content with retained
target, including all original/typed/final evidence and Existing/Fresh provenance.
Missing/foreign proof or changed draft refuses before response. Do not manufacture
v2 readiness or treat a caller's derived summary as a successful comparison.

Use the existing qualified lossless parser and field/child locator scanner.
Placeholders cover every mapped field/reference occurrence with its stable
opaque value token; unmapped concrete content may remain. Raw preserves exact
characters; Formatted is explicitly display-only. Preserve full-document consent,
unreadable-field refusal, four-Mi-character response bound and original v2 output.
Computed groups have no invented XML locations. This slice introduces no computed
page, HTTP route, export or browser availability.

The owning view/direct comparison supplies one cancellation flag, signals it on
retirement, invalidation or close, and rechecks original lease/revision/generation
and the original inspection-validity and active-operation identities before
returning. Every completed, cancelled or expired reinspection signals existing
work/view controls when it replaces or invalidates retained evidence, even if
revision and inspection validity have the same values again. Unchanged retained
current content remains inspectable after a failed inspection; this confers no
valid target or export authority. Nested view materialization retains its separate work flag.
Every full verification/scan uses the same original comparison control, with
checks before/after bounded parser calls and per inventory/entity scan. A default
controlled comparison port refuses v3; legacy v2 adapters keep their behavior.
No late returning success survives cancellation. Existing shared scratch and
response reservations remain required. Additional proof recomputation/retention
must be included in later resource qualification.

Acceptance uses independent mock XML: all three modes, concrete value/identity
edits and Fresh replacement, optional absence/unresolved draft, stale complete
proof/draft/pins, consent and cancellation during comparison, unchanged v2 outputs.
Actual publication remains unqualified; tests cannot enable runtime behavior.
