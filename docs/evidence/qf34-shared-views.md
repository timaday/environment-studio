# Shared controlled v3 physical and computed views

Internal v3 views now present physical documents/entities/relations, draft and
placement choices, concrete bindings and every affected location. Separate typed
pages present computed nodes, memberships, co-occurrences, complete contributors
and rule outcomes. Every request freshly verifies complete original and retained
target XML/proofs under the pinned ViewAdmission's original cancellation and
before/after owner checks. No HTTP route or runtime availability is enabled.

Physical references retain opaque Existing/Fresh provenance after identity edits
and same-literal replacement. Computed nodes have no physical handle, editable
field or invented XML origin. Contributor links map through final content's
provenance, with final observed XML locations and all ordered field roles.
Duplicate values retain every contributor; self-co-occurrence retains both roles
even when their locations are equal. Secret fields stay masked. Missing target,
absent field, Fresh current unavailability and unresolved decisions remain distinct.
Complete rule failures stay inspectable without becoming validation success.

See the [physical](../contracts/plan-physical-views-v3.md) and
[computed](../contracts/plan-computed-views-v3.md) contracts. Both keep complete
totals and bounded pages, exact ordering, original controls and mandatory location
disclosure. Legacy uncontrolled v3 helpers refuse; v2 behavior stays unchanged.
