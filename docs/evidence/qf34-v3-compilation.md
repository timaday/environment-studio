## Implemented boundary

The adapter selects only the packaged closed v3 source schema after bounded
parsing. It reads the existing physical value types and separate immutable
computed declarations. It never reinterprets a v2 compilation result as v3.
Unknown shape/authority, malformed Unicode, duplicate keys, unsupported YAML,
numeric coercion and parser/declaration budget violations refuse safely.

The core checks physical/computed type separation, exactly one derivation per
computed type, PUBLIC readable text source eligibility, unique relation/rule
namespaces, same-source co-occurrence endpoints and declared count/cardinality
constraints. Missing physical mapping support remains incomplete; semantic
errors reject without a checked v3 model. Reused physical checks preserve their
v2 semantics; their digests/readiness are discarded before v3 result construction.
Every valid v3 declaration returns incomplete with `MECHANISM_UNQUALIFIED`.
Uploaded content has no route to register availability.

Java logical/binding digests match the independent
[contract fixtures](qf34-v3-contracts.md), including binding-specific child
dependencies. Two additional Python-derived controls cover reversed direction
and exact Unicode plus a 101-digit integer. Source order, labels and native
metadata do not change compatibility; old v2 adapters and hashes remain unchanged.
These tests validate definition bytes, not observed values or derived groups.
