## Implemented boundary

The new closed configuration schema precedes the implementation. JSON admission enforces the 1 MiB/depth-8/10,000-token limits, duplicate/unknown-field rejection, strict Unicode and canonical integer tokens, bounded collections, unique client families/destination IDs and matching physical identity shapes. No YAML, property bag, environment interpolation or credentials are accepted.

External files use bounded single reads, no-follow secure directory traversal, regular-file checks and root/operator ownership/write-mode checks. Candidate Linux POSIX-ACL filesystem types are explicit; unknown filesystem semantics refuse. Group/other writes refuse except sticky ancestors whose next component is root/operator owned. The [Linux POSIX ACL mask mapping](https://man7.org/linux/man-pages/man5/acl.5.html) explains the write-mode check for named ACL entries. Actual local file tests ran on ext4. This is not an atomic-open guarantee against concurrent root/same-UID modification; the contract explicitly treats those actors as trusted. No claim of NFS or other untested ACL semantics is made.

Trust admission hashes/parses the same certificate-only PEM bytes, bounds certificates to 128 and the input to 1 MiB, rejects private/other blocks and trailing content, checks validity and retains defensive copies. Package admission matches the independent archive digest, strict four-member inspector, all metadata and exact regenerated SQL bytes. Oracle boundaries come only from that same generator. A package containing an appended COMMIT with otherwise recomputed ZIP/member integrity is refused by regeneration comparison.

The tools-only native port creates a new session using fixed `--fork --wait --` launcher arguments, clears inherited environment, owns one stdin and one merged output channel, bounds transcript/output and writes, tracks descendant process start identities and reports cleanup uncertainty. Password buffers are bounded while reading and wiped at close. The ordinary console adapter deliberately remains unavailable pending bounded input-drain/echo/restoration qualification.

The protocol implements the frozen PostgreSQL and SQL*Plus settings grammar, initial password prompts, Oracle banner/SHOW lines, first-SQL ordering, 120-second shared transaction deadline, exact nonce/archive/program readiness frames, sole commit, acknowledgement and clean-exit requirements. Before commit, errors cannot regain commit authority. After any possible commit delivery, absent acknowledgement/clean exit remains UNKNOWN. Oracle sends only generator-supplied block boundaries with supervisor-owned slash terminators. A usable precommit client receives fixed cleanup/rollback and must acknowledge it before cleanup Complete. Tool-resource cleanup uncertainty remains visible after acknowledged APPLIED.

Native PostgreSQL TLS command/runtime preparation, Oracle passwordless certificate-only wallet preparation, exact Java/native installation qualification and ordinary console restoration are not enabled by these internal mechanisms. The lead explicitly reserved these for D07c2. No database was accessed by this slice.
