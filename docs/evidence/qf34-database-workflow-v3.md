## Actual path and checks

The retained disposable lab's ownership labels are checked before provisioning
fresh invented owners. Passwords remain in memory, outside process arguments and
source files. Actual write-capable owner controls prove committed writes and
read-only transaction DML denial only in these owned test databases. Production
observation remains read-only and operation-scoped.

Both Oracle and PostgreSQL observations use verified TLS, exact complete two-record
XML inventory and separate v3 fingerprints. A present empty derived identity first
refuses. The test owner then commits an explicitly invented nonempty replacement;
fresh observation supplies the actual sources for the following checks:

- Editing one physical value merges two groups. Complete contributors remain
  alpha and beta, and independently expected complete XML bytes match, including
  escaping, whitespace and the supplementary Unicode character. Original and
  final source pins remain separate.
- Capture maps three physical entities to neutral slots and retains their two
  physical references. JSON/YAML re-import agrees. Encoded profile bytes exclude
  the independently enumerated donor identities/values, computed type and
  contributor/source/XML markers.
- Partial reuse previews the selected physical slot and required physical
  dependency; whole reuse previews all slots. Both identify the declared
  derivation, preserve all original physical entities/edges and introduce explicit
  fresh target values. Unselected XML and the other document remain exact.
- Removing the last contributor to the old group removes that group while keeping
  the complete remaining physical/derived result. Fresh references map to the
  independently expected final element positions.
- Complete expected node, membership and contributor sets match. Every source-field
  role, actual final document/element/digest, attribute name/quote/decoded value and
  raw value span is checked. Preliminary Entered proofs contain no donor pin;
  KeepObserved proofs retain their original entity/source location.
- Stale capture, cancelled capture and unresolved target input refuse. After the
  pure planning workflow, independently queried committed database state remains
  unchanged and the owned account has no remaining database session.

The helper also repeats the existing connected cancellation, wrong trust and wrong
hostname controls. Cancellation closes credentials/connection and leaves state
unchanged. TLS-negative attempts retain CLEANUP_INCONCLUSIVE; absent database
sessions do not promote cleanup certainty. Controlled certificate/hostname inputs
support the TLS failure inference; the production public result does not expose
the specific driver cause. Existing fixture-size and Oracle4000-character state
witness limits from the observation evidence still apply.

The external helper explicitly translates the physical composition proposal into
typed target decisions. That translation is qualification code, not a completed
hosted composition service. These finite cases use direct-attribute mappings and
one derivation. They do not newly qualify child mappings, co-occurrence, cross-
document moves, all account variants, maximum resources, native clients or UI.
Those existing separate tests and remaining integrated gates retain their scope.

## Traceability

The first extension passed with group counts/values and selected origin checks.
Its source/log/result are retained with `attempt1` names. The helper was then
strengthened to compare every contributor and membership proof, and rerun
successfully on both engines. Independent review then found that expected
additions/counts were derived from the composition output. A silently omitted
addition could shrink both result and expectation together. Attempt2 is retained.

The final helper first requires the exact independently requested new slot/type
list, retained keys/edges and proposed references. Subsequent expected values,
counts and origins use that independent list. The reviewer accepted the correction,
and the final helper passed again on both engines. This was an evidence defect,
not a reproduced production composer defect. No production source changed.
